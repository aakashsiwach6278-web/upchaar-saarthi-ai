# 🏥 उपचार-सारथी AI (Upchaar-Saarthi AI)
**Track 06: Health | Code for a Billion — Bharat Agentic-AI Hackathon 2026**

### 🎯 Problem Statement (ज़मीनी समस्या)
Over **833 million people** in rural India (such as Amroha, Uttar Pradesh) lack permanent digital health records. Patients frequently lose paper prescriptions and forget critical drug allergies (like Paracetamol hypersensitivity), leading to nearly **5.2 million medical errors** annually. Heavy healthcare apps also crash or lag on slow rural internet connections.

### 💡 Our Solution (हमारा समाधान)
**Upchaar-Saarthi AI** is a lightweight, fault-tolerant Agentic Healthcare Assistant built specifically for rural India:
- **🧠 Permanent Cloud Memory (Upstash Redis):** Remembers patient medical history and life-threatening allergies across sessions permanently.
- **🚨 3-Level Smart Emergency Triage:** Classifies symptoms automatically into **🟢 Green (Home Care)**, **🟡 Yellow (Consult Doctor)**, and **🔴 Red (Emergency — Call 108 Ambulance immediately)**.
- **🔗 xSpan CareHub API Integration:** Syncs patient allergy profiles and digital twin health records seamlessly.
- **📖 Live Medical Verification:** Uses real-time Wikipedia Tool integration and ultra-fast **Groq AI** inference for reliable answers even on weak internet.
- **🌐 Clean Web Interface (`index.html`):** User-friendly hospital-style chat portal designed for rural accessibility.
